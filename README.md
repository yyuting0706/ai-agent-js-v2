## Embeddings 相似度測試

測試程式位於 `scripts/test-similarity.js`，使用 `text-embedding-3-small` 取得
三組句子的向量，再以餘弦相似度計算每組內的兩兩相似度。

```bash
npm run similarity
```

執行前請在 `.env` 設定 `OPENAI_API_KEY`。本次測試輸出如下：

```text
使用 text-embedding-3-small 計算兩兩句子相似度

## 第 1 組：意思相近
我喜歡貓 <-> 貓咪很可愛: 0.6991
我喜歡貓 <-> 我養了一隻貓: 0.6746
貓咪很可愛 <-> 我養了一隻貓: 0.5538

## 第 2 組：意思不同
今天天氣很好 <-> 我要去買菜: 0.2873
今天天氣很好 <-> 電腦壞了: 0.2356
我要去買菜 <-> 電腦壞了: 0.2414

## 第 3 組：自訂案例
我每天早上跑步 <-> 運動讓身體更健康: 0.4459
我每天早上跑步 <-> 我喜歡看科幻電影: 0.2065
運動讓身體更健康 <-> 我喜歡看科幻電影: 0.2000
```

第 1 組的相似度明顯高於第 2 組，符合三句都在談貓、而第 2 組主題各不相同的預期。
第 3 組中跑步與健康仍有部分語意關聯，因此分數高於和科幻電影的配對。
